\# 🦠 COVID-19 Global Trend Analysis (2024)



\## 📌 Overview

An end-to-end data science project analyzing COVID-19 trends across 170+ countries

using real-world data from Our World in Data. Includes data cleaning, exploratory

data analysis, machine learning forecasting, and interactive visualizations.

This project was built using Python in Jupyter Notebook.



\## 🛠️ Tech Stack

\- \*\*Language:\*\* Python

\- \*\*Libraries:\*\* Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Plotly

\- \*\*Tools:\*\* Jupyter Notebook, Git, GitHub



\## 📊 Key Highlights

\- Analyzed 170+ countries for 2024 COVID-19 trends using Our World in Data dataset

\- Cleaned and processed 586,000+ rows of epidemiological data

\- Performed EDA — top 10 countries by cases, global daily trends, death rates

\- Built Random Forest forecasting model with lag features and rolling averages

\- Created interactive world map (choropleth) and country comparison dashboard

\- Compared trends across India, USA, Brazil, and United Kingdom

\## 📂 Dataset

\- \*\*Source:\*\* Our World in Data (OWID)

\- \*\*Link:\*\* https://covid.ourworldindata.org/data/owid-covid-data.csv

\- \*\*Size:\*\* 586,000+ rows, 61 columns

\- \*\*Coverage:\*\* 170+ countries, 2020–2024

\- \*\*Features used:\*\* total\_cases, new\_cases, total\_deaths, new\_deaths,

&#x20; total\_vaccinations, people\_vaccinated\_per\_hundred, population



\## 🤖 Machine Learning Model

\- \*\*Model:\*\* Random Forest Regressor

\- \*\*Target:\*\* Daily new COVID-19 cases (India)

\- \*\*Features:\*\* Day number, 7-day lag, 7-day rolling average

\- \*\*Split:\*\* 80% train / 20% test

\- \*\*Metrics:\*\* R² Score, Mean Absolute Error (MAE)
